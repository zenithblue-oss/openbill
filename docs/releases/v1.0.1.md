# OpenBill v1.0.1

Small update on top of 1.0.0. No database change (schema stays at version 11).

## What is new

- Update notice (desktop): once a day OpenBill asks GitHub for the latest release number and
  shows a dismissible banner with a link to the release page when a newer version exists.
  Nothing is downloaded or installed, and no business data is sent. Turn it off under
  More > About > Check for updates. Android has no network permission, so it never checks and
  the setting is hidden there.
- What's new: after an update, the changes for the running version are shown once. Reopen them
  from More > About > What's new. Fresh installs do not show it.

Versions: Android 1.0.1 (code 8), desktop 1.0.1, CLI 1.0.1.
