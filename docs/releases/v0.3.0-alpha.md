# OpenBill v0.3.0-alpha

The 1.0 feature-complete scope (all 136 P0 features, see ROADMAP.md).

## Upgrading: new package id

The application id is now `com.zenithblue.openbill` (was the old id), so Android treats this as a
different app and it does not update the old install in place. Make a backup in the old app,
install this build, then restore the backup. Uninstall the old app only after checking the data.

## What is new

- Parties: several shipping addresses, each with a ship-to GSTIN; party notes and attachments.
- GST: place of supply for goods follows the default ship-to state (IGST Act s.10(1)), so a
  ship-to in another state is billed with IGST. The place of supply can still be changed by hand.
- Items: alternate unit with conversion on bill lines, also when a draft is reopened; batches or
  serials, not both.
- Reports: low-stock report (app and `openbill report low-stock`).
- Printing: ESC/POS thermal receipts (Bluetooth, print services, serial), silent print.
- Security: app lock (PIN, biometric on Android) with exponential backoff, idle lock on desktop,
  password-encrypted backups, erasing a business removes its rows, audit log, files and logo.
- Database schema version 9, migrating from every earlier version.

Versions: Android 0.3.0-alpha (code 6), desktop 0.3.0, CLI 0.3.0.
